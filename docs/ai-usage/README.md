# Registro de uso de IA

> Política del cliente: el uso de IA está permitido; el resultado generado por
> IA **no es evidencia de competencia**; "lo recomendó la IA" no es una
> justificación técnica. Todo integrante debe poder explicar, revisar,
> modificar, probar y defender cualquier artefacto.
>
> Todo uso relevante de IA se registra aquí con una entrada nueva en
> `entries/`. Las entradas son representativas y deben incluir al menos un
> caso **aceptado tras verificación**, uno **modificado por deficiencia** y
> uno **rechazado con razón técnica**.

## Formato por entrada (`entries/<fecha>-<tema>.md`)

```markdown
# Uso de IA — <fecha> — <tema>

- Instrumento/herramienta: <ej. claude, opencode, copilot>
- Objetivo: <qué se intentaba lograr>
- Resultado recibido: <qué produjo la IA>
- Revisión realizada: <qué se inspeccionó y con qué criterio (tests, lectura, comparación ADR)>
- Cambios aplicados: <qué se corrigió / adaptó>
- Prueba añadida / verificación: <cómo se verificó lo aceptado>
- Aprendizaje: <qué dejó el ejercicio / confirmación o desviación técnica>
- Resultado: ACEPTADO tras verificación | MODIFICADO por deficiencia | RECHAZADO
```
