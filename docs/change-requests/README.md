# Solicitudes de cambio (Change Requests)

> Todo cambio sobre la línea base (requisitos, arquitectura, alcance) llega
> por un Issue clasificado como **solicitud de cambio** y requiere presentar
> análisis de impacto ANTES de implementar (requisito del cliente; obligatorio
> en el Hito 3).

## Formato por CR (`<NN>-<tema>.md`)

```markdown
# CR-<NN> — <tema>

- Fecha: <aaaa-mm-dd>
- Solicitante: <cliente/equipo>
- Contexto y motivación:
- Impacto en requisitos (RF/RNF):
- Impacto en arquitectura/ADR:
- Impacto en estimación/cronograma:
- Impacto en riesgos:
- Impacto en plan de verificación (casos):
- Decisión de aceptación: ACEPTADO | ACEPTADO CON EXCEPCIONES | RECHAZADO
- Aprobado por:
```
